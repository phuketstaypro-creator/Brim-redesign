# BRHK Redesign V3

Фактическая многостраничная версия прототипа нового сайта БРХК.

## Реализовано

- отдельные маршруты основных страниц;
- разделы «Школа креативных индустрий» и «Балет для всех»;
- обязательная структура `/sveden/` и 14 подразделов;
- новости, афиша, документы, студенты, контакты и галерея;
- панель версии для слабовидящих: размер текста, цветовые схемы, отключение изображений и анимации;
- клавиатурная навигация, skip-link, заметный focus;
- шаблоны политики персональных данных и согласия;
- отсутствие аналитики, рекламных пикселей и внешних шрифтов;
- CMS-маркеры `data-cms-field` для интеграции с существующей админкой;
- Vercel rewrites для прямого открытия всех маршрутов.

## Граница работ

Это дизайн, клиентский код и структура шаблонов. Полный импорт архива, подключение действующей CMS и базы, заполнение официальных сведений, проверка реальных документов, серверные формы и финальный юридический аудит выполняются на этапе интеграции вместе с технической командой Заказчика.
