# БРХК — рабочая версия редизайна

Промежуточная production-сборка для согласования дизайна, структуры, мобильной версии и доступности.

- реальный фотоматериал БРХК встроен локально;
- маршруты основных разделов работают через Vercel rewrites;
- предусмотрены новости, документы, `/sveden/`, ШКИ и «Балет для всех»;
- версия для слабовидящих сохраняет настройки локально;
- формы и аналитика не подключены;
- финальная CMS-интеграция и миграция архива выполняются после получения экспорта заказчика.
